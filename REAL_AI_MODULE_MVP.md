# Real AI Module MVP Requirements

This document explains what AegisForge AI needs to launch the first real AI module MVP.

## Recommended first AI module

Start with **AI App Blueprint Generator** instead of full app generation.

User enters a prompt like:

> Build me a food delivery app for Lagos with vendors, riders, customers, payments, and admin dashboard.

Backend returns:

- App summary
- User roles
- Core features
- Suggested pages/screens
- Database schema
- API endpoints
- Security checklist
- Deployment plan
- Monetization ideas
- Suggested tech stack

This is useful, affordable to run, and becomes the foundation for the future full AI App Builder.

## What you need

### 1. AI provider

Choose one:

- OpenAI
- Anthropic Claude
- Google Gemini
- Groq
- OpenRouter

Recommended MVP choice: **OpenAI or OpenRouter**.

Environment variables would look like:

```env
AI_PROVIDER=openai
OPENAI_API_KEY=sk_xxx
AI_MODEL=gpt-4o-mini
```

or:

```env
AI_PROVIDER=openrouter
OPENROUTER_API_KEY=sk-or-xxx
AI_MODEL=openai/gpt-4o-mini
```

### 2. Backend endpoint

Add an endpoint like:

```txt
POST /ai/app-blueprint
```

Request:

```json
{
  "idea": "Build me a food delivery app",
  "audience": "small businesses in Nigeria",
  "platform": "web app",
  "budget": "lean startup"
}
```

Response:

```json
{
  "summary": "...",
  "roles": [],
  "features": [],
  "pages": [],
  "database_tables": [],
  "api_endpoints": [],
  "security_checklist": [],
  "deployment_plan": [],
  "monetization": []
}
```

### 3. Supabase table for AI generations

Create a table to track prompts and outputs:

```sql
create table if not exists public.ai_blueprints (
    id bigint generated by default as identity primary key,
    email text,
    idea text not null,
    output jsonb not null,
    created_at timestamptz not null default now()
);
```

### 4. Limits

Protect cost with limits:

- Free: 1 blueprint/day or waitlist-only
- Starter: 3 blueprints/month
- Pro: 20 generations/month
- Business: 75 generations/month

### 5. Frontend module UI

Add a page or section:

```txt
AI App Blueprint Generator
```

Fields:

- App idea
- Target users
- Platform
- Budget/stage
- Email optional/required

Buttons:

- Generate Blueprint
- Join Waitlist to Save
- Download Blueprint

### 6. Safety and quality

Add:

- Prompt length limit
- Abuse/rate limiting
- No illegal app generation policy
- JSON schema validation
- Error handling
- Generation logging

## Best MVP path

1. Add AI provider key to backend.
2. Build `/ai/app-blueprint` endpoint.
3. Add Supabase `ai_blueprints` table.
4. Add frontend blueprint generator UI.
5. Limit free generations.
6. Add downloadable blueprint report.
7. Later connect it to paid plans.
